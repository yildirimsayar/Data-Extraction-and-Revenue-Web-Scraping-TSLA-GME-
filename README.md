# Tesla & GameStop Stock and Revenue Analysis

This project analyzes **Tesla (TSLA)** and **GameStop (GME)** by combining historical stock price data with company revenue information.

Stock price data is extracted using the `yfinance` library, while quarterly revenue data is obtained through web scraping. The project visualizes stock price trends alongside revenue figures to provide a clearer view of each company’s financial performance over time.

## Key Steps
- Extract historical stock prices using yfinance
- Scrape quarterly revenue tables via web scraping
- Clean and prepare financial data
- Visualize stock prices and revenues together

## Technologies Used
- Python
- yfinance
- Pandas
- BeautifulSoup
- Matplotlib
